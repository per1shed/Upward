# Upward

Telegram-бот для командного учёта **дневной продуктивности**: время за день, отдых, прорывные дни и общая статистика с графиками.

## Возможности

- **✅отметить** — записать время за сегодня в формате `ЧЧ:ММ` (повторный ввод суммируется)
- **отдых** — отметить день отдыха
- **прорыв** — отметить значимый день (⭐ на графиках, время сохраняется)
- **📊 Статистика** — общий прогресс команды и месячный график
- **⭐ Календарь прорывов** — годовой календарь с прорывными днями всех участников

## Требования

- Python 3.11+
- Токен бота от [@BotFather](https://t.me/BotFather)

## Установка

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=ваш_токен
TZ=Europe/Moscow
```

`TZ` — часовой пояс для «сегодня» и автозаполнения пропущенных дней (по умолчанию `Europe/Moscow`).

## Запуск

```bash
python main.py
```

Данные хранятся локально в `progress.db` (создаётся автоматически).

## Команды

| Команда   | Описание              |
|-----------|------------------------|
| `/start`  | Главное меню           |
| `/log`    | Отметить день          |
| `/stats`  | Статистика и график    |

## Структура

| Файл           | Назначение                          |
|----------------|-------------------------------------|
| `main.py`      | Точка входа                         |
| `handlers.py`  | Обработчики Telegram                |
| `database.py`  | SQLite, записи по дням              |
| `charts.py`    | Графики и календарь прорывов        |
| `keyboards.py` | Inline-кнопки                       |
